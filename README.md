# Mecha-Arena

Proyecto B: Simulador de Robots y Combate Táctico.

Mecha-Arena es un proyecto desarrollado en Python donde los usuarios podrán crear y personalizar mechas para enfrentarlos en combates tácticos por consola.

## Módulos del proyecto

- Creación y personalización de mechas
- Sistema de combate por turnos
- Validaciones y control de datos
- Menú principal e integración general

## Tecnologías

- Python 3.x
- Git
- GitHub
- Visual Studio Code
